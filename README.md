# LAST TRAM — A Pixel Story

A tiny interactive story built around a single piece of pixel art: an abandoned tram slowly being reclaimed by a forest.

## ✦ Concept

> **The city disappeared. The tracks remembered the way.**

The project turns one atmospheric pixel-art scene into a small narrative experience. The reader enters the tram, makes a choice, and discovers one of two endings.

## ✦ Run locally

No framework or build step is required.

```bash
git clone https://github.com/YOUR_USERNAME/last-tram-pixel-story.git
cd last-tram-pixel-story
```

Then open `index.html` in your browser.

For the best experience, use GitHub Pages after pushing the repository.
